 🌍 Safarnama

Safarnama is a travel and hyperlocal discovery platform designed to help users discover places, plan journeys, explore destinations, and interact with location-based experiences.
 ✨ Features

- 🗺️ Interactive maps
- 📍 Location-based place discovery
- 🛣️ Road distance and route calculation
- 🔐 User authentication
- ⭐ Reviews and ratings
- 📋 Travel history
- 📍 Saved addresses
- 📱 Responsive interface
- 🌐 Modern travel-focused UI

 🛠️ Tech Stack

- React
- TypeScript
- Vite
- TanStack Start
- Supabase
- MapLibre GL JS
- OpenStreetMap
- OSRM

 🗺️ Maps & Routing

Safarnama uses an open-source mapping and routing stack:

- **MapLibre GL JS** — map rendering
- **OpenStreetMap** — map data
- **OSRM** — road routing, distance and estimated duration

This avoids dependency on Google Maps Platform for map and routing functionality.

 🔐 Authentication & Database

Supabase is used for:

- Authentication
- User profiles
- Database
- Reviews
- Travel data
- Address management
